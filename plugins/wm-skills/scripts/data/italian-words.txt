# Parole italiane che non devono comparire in un identificatore.
#
# Una parola entra in questa lista solo se è inequivocabilmente italiana: niente che sia
# anche una parola inglese di uso comune nel codice — `data`, `area`, `media`, `base`,
# `info`, `note`, `file`, `test`, `finale`→`final`, `costante`→`constant` non ci stanno,
# perché il controllo le troverebbe addosso a codice scritto bene.
#
# Il confronto è su token interi, dopo aver spezzato camelCase e snake_case: `getUno`
# dà `get` + `uno`, e `uno` è qui. Una parola di tre lettere o meno fa troppo rumore e
# non si aggiunge.
#
# Una riga che inizia con # è un commento; le righe vuote si ignorano.
